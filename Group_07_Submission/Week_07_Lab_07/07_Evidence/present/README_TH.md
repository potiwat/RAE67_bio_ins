# คลิปเล่นกับโคมจริงและข้อมูลรอบเดียวกัน

**[ดูคลิปบน YouTube](https://youtu.be/-zckfxbT9Jk?feature=shared)** · [วิดีโอต้นฉบับ IMG_4568.MOV](IMG_4568.MOV)

ผู้เล่นโต้ตอบกับโคม LampBio-Inpire ผ่านตัวเปิดที่เรียกในชุดส่งนี้ว่า `present` เมื่อวันที่ 12 พฤศจิกายน 2569 วิดีโอยาว **632.180 วินาที** และช่วงเวลา feedback แรกถึงสุดท้ายยาว **631.926 วินาที** (ต่างกัน 0.254 วินาที) ไฟล์ที่แนบมี SHA-256 ตรงกับต้นฉบับบน Desktop ทั้งไฟล์ ระยะเวลาที่ใกล้กันเพียงอย่างเดียวยังระบุตำแหน่งเฟรมที่ตรงกับเวลา 0 ของ CSV ไม่ได้

| ไฟล์ | สิ่งที่วัด |
|---|---|
| [present_feedback.csv](present_feedback.csv) | 64,212 แถว ครบ ID1–5 และพบทั้ง 6 อารมณ์ มีเป้ามอเตอร์ ตำแหน่ง encoder ความเร็ว โหลด กระแสในหน่วยรีจิสเตอร์ แรงดันและอุณหภูมิ |
| [present_events.csv](present_events.csv) | 338 รายการจากทั้ง 4 ช่วง มีบริบทการเล่นและเหตุการณ์ระบบ Safety |
| [Last_Owner_FSM_Events.csv](Last_Owner_FSM_Events.csv) | บันทึก FSM ที่ตัวเปิดเก็บไว้เฉพาะช่วงสุดท้าย |
| [Last_Viewer_Status.json](Last_Viewer_Status.json) | สถานะกล้อง ระยะ จังหวะ และประวัติขอบ GPIO ที่ยังอยู่ในตัวเก็บของช่วงสุดท้าย เป็นภาพสถานะหนึ่งเวลา |
| [SESSION_VERIFICATION.json](SESSION_VERIFICATION.json) | ช่วงเวลา จำนวนแถวแยกข้อ ข้อมูลวิดีโอ และ SHA-256 ของไฟล์ |

เปิดหน้าต่างครั้งเดียว ตัวบันทึกมอเตอร์แบ่งเป็น 4 ช่วงระหว่างการเล่นและการคืนท่าจาก Safety มีคำร้องหยุดจาก ID1, ID4 และ ID2 ตามลำดับ `elapsed_s` นับจาก feedback แรกของหน้าต่างนั้น และ `recording` บอกช่วงที่มาของแถวนั้น การสาธิตนี้แยกจากรอบเปรียบเทียบ C0/C1 ที่กำหนดสิ่งเร้าไว้ล่วงหน้า
