# Lab 04 Artificial Hormone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete receptor normalization and the one-step hormone update, then generate fresh comparison and extreme-input evidence.

**Architecture:** Preserve the two public functions in `student_hormone.py`. Validate the receptor boundary first, compute all rates from the old hormone state, update once, clamp only the new state, and use the supplied runner for deterministic profiles.

**Tech Stack:** Python 3.10+, Python standard library, supplied subprocess checker and HTML/CSV runner.

**Spec:** `docs/superpowers/specs/2026-11-14-all-labs-design.md`

## Global Constraints

- Do not copy prior-student code, figures, report text, or results.
- Use only the Python standard library for the student implementation.
- Preserve `raw` before the final hormone clamp.
- Record proposed predictions before opening data-generating run outputs.
- Label all numerical results as a proposed course model, not robot validation.

## Review Focus

- Nonfinite receptor arguments and `h_max <= h_min` must raise `ValueError` (Task 2 focused test).
- Receptor normalization must clamp below 0 and above 1 (Task 2 checker).
- Production, clearance, and binding must all use the old state (Task 2 checker).
- Invalid stimulus must reset every returned numeric state/rate to zero and set `fault=1` (Task 2 checker).
- The returned `raw` value must remain unclamped when `h` saturates (Task 2 checker).
