## Review Focus

- Safety event priority must remain `fault`, `near`, then `clear` before positive events (Task 2 checker).
- `afraid` must hold for all non-safety events (Task 2 checker).
- `timeout` returns only `interested`/`happy` to `normal` (Task 2 checker).
- `idle` changes only `normal` to `sleepy` (Task 2 checker).
- Replay must preserve raw/event traces when policy/config/input are unchanged (Task 3 comparison).
