# แก้ขอบเขตการถ่าย Lab07 ตามคำขอผู้ใช้

ผู้ใช้ชี้ว่าชุดถ่ายเพิ่มมากเกินไปและให้ยึดตารางSimulation C0/C1และReal robot C0/C1อย่างละ3repeats

ตรวจต้นฉบับ Week07_Student_Worksheet_TH.docx ที่ผู้ใช้ให้แล้ว พบข้อกำหนด >=3repeatsต่อcondition ทั้งsimulation/realและscenarioเล่นกับคน10นาที แต่ไม่พบการระบุจำนวนวิดีโอหรือว่าต้องถ่ายทุกtrial ข้อความ12trials/120นาทีเป็นกรณีถ้าทุกtrial10นาที รวมsimulation6และreal6 ไม่ใช่12คลิปฮาร์ดแวร์

ยกเลิกคำแนะนำให้ถ่ายcomponentเพิ่ม6คลิปนอกเหนือจากreal6รอบของตาราง แผน12คลิป96นาทีในผลPCเป็นข้อเสนอที่ผู้ช่วยเพิ่ม ไม่ใช่ข้อกำหนดอาจารย์ และถูกแทนที่ด้วยเอกสารนี้ เก็บsimulation/ผลPC/รายงานเก่าไว้เป็นprovenance ไม่ลบทิ้งหรือเปลี่ยนraw

แนวทางถัดไป:ใช้การทดลองrealแบบควบคุมอัตโนมัติเป็น6รอบหลัก (C0/C1อย่างละ3) ไม่บวกชุดถ่ายcomponentอีก6รอบ ผู้เล่นนั่งให้กล้องเห็นหน้าและคอยหยุดหากจำเป็น โปรแกรมป้อนscriptedexperimentalinputเวลาเดียวกันให้ทั้งคู่ ต้องติดป้ายให้ชัดว่าเป็นscriptedinputบนฮาร์ดแวร์ ไม่ใช่กดGPIO/ToFจริงโดยมนุษย์ บันทึกinputจริง/ToFจริงแยกและคงsafetyoverrideเดิม

การนั่งหน้าเฉยๆในรอบควบคุมไม่แทนหลักฐานinteractionกับคน10นาทีอัตโนมัติ ต้องรักษาข้อกำหนดscenarioนี้แยกจากการวัดเหตุผลAHM→CPG โดยไม่กล่าวอ้างว่าวิดีโอpilotสั้นที่มีอยู่ครบ10นาทีแล้ว หรือเพิ่มจำนวนคลิปเองอีกครั้งก่อนทบทวนบทที่ใช้

Simulationมีแล้ว3pairedreplaysครบ6stateในระดับAHM/SO2bank (36state-components) เป็นdeterministicแบบจำลอง ไม่ใช่ฟิสิกส์หรือencoderหุ่นจำลอง และยังไม่ใช่3รอบrealใหม่ ตัวhardwareadapterสำหรับscriptedmeasurementยังไม่เชื่อมกับownerPi จึงยังไม่พร้อมให้ถ่ายrealตามscriptจนกว่างานนี้ผ่านmockedowner/safety/recordingchecksและreadinesspilot
