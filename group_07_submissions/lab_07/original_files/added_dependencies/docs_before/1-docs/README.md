## Markdown และเอกสารสนับสนุน

- `markdown/` — ใบงาน Markdown, คู่มือ ROS, ตำแหน่งไฟล์ และบันทึกการออกแบบ
- [ใบงาน Markdown](markdown/worksheet.md)
- `references/` — เอกสารรายวิชาต้นทาง การนำงานเดิมมาใช้ และ attribution; ไม่ใช่ source code
- `metadata/` — ข้อมูลที่มาของใบงาน สมาชิก และสถานะ package
- `checks/` — รายงานตรวจที่มนุษย์อ่านและ mapping; logs/ผลตรวจ JSON อยู่ `../3-results/repository_qa_20261106/`
